# Writing Content

## Format
All blog posts are now **MDX** files (`.mdx`). This allows you to include interactive components and embed content easily.

## Auto-Embeds
To embed a tweet, YouTube video, or other supported media, simply paste the URL on its own line.

**Example:**
```md
Here is a cool tweet:

https://twitter.com/astrodotbuild/status/123456789

That's it!
```

## Supported Embeds
- Twitter / X
- YouTube
- Vimeo
- Bluesky
- Mastodon
- GitHub Gist

## Frontmatter
Standard frontmatter applies.

```yaml
---
title: "My Post"
pubDate: 2026-01-11
description: "A description."
---
```
